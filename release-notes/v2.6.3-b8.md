# GreenPass 2.6.3 (сборка 8)

- Versioning: the shown version goes back to 2.6.3, and updates are now ordered by a build number, like Telegram Desktop. Releases are tagged `v2.6.3-b8`, `v2.6.3-b9`, … and auto-update installs any build newer than the installed one.
- If you have 2.6.4–2.6.6 installed, install this build once by hand: those versions compare the old version numbers and will not pick it up.
- WARP: every new config uses a random WARP port (2408, 500, 1701 or 4500) instead of always 2408. In Russia DPI often blocks one port while another works.
- AWG self-healing reacts faster: a check every 30 s, a fix after 2 failed checks in a row, at most once per 3 minutes.
