**Файлы**
- `GreenPass.elyx` — структурированный плагин (Elyx), exteraGram 12.5.1+, SDK 1.4.5.0+
- `GreenPass.plugin` — однофайловая версия для клиентов без Elyx, exteraGram 12.5.1+, SDK 1.4.4.3+

**Изменения**
- Обновлено под текущую документацию SDK exteraGram: `app_version`/`sdk_version` вместо устаревшего `min_version`
- Мульти-аккаунт: экспорт настроек в «Избранное» отправляется с того же аккаунта, чей ID взят; файлы из сообщений ищутся по аккаунту сообщения
- Kill switch при смене прокси приостанавливает сеть на всех залогиненных аккаунтах, а не только на открытом; в фоне не снимает паузу, выставленную самим приложением
- Исправлены «кракозябры» в русских строках (ошибки Relay, названия olcRTC, «Текущий», описание плагина, определение русского языка)
