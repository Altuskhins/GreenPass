# GreenPass 2.6.3 (сборка 13)

- TG WS: updated to tg-ws-proxy v1.11.4.
  - TLS now offers only X25519. The X25519MLKEM768 key share made the ClientHello big enough to trigger DPI, which showed up as TimeoutError.
  - CF H2: native packets with up to 256 bytes of padding are no longer rejected, and packet replay tracking is more accurate.
  - CF H2: the recovery loop no longer gets stuck on Python 3.8-3.11.
  - CF H2: a connection that stops receiving data is reconnected after a timeout instead of hanging.
  - CF H2: flow-control updates and uploads are sent in 64 KB batches, so media loads faster.
  - WebSocket: large frames are masked faster.
- CI: GitHub Actions bumped to v7.
