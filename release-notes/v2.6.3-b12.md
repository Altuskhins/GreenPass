# GreenPass 2.6.3 (сборка 12)

- AWG/WARP: the WARP config MTU is now 1200 instead of 1280. On mobile networks that carry IPv4 over IPv6 (464XLAT), the 1280 tunnel produced UDP packets that were too big. The core logged "sendmsg: message too long" and every connection hung for ~2 minutes. WARP configs that are already saved are lowered to 1200 automatically on the next connect.
