# GreenPass 2.6.1

## AmneziaWG
- GreenPass now checks the AWG tunnel every minute. After 3 failed checks it re-downloads the free config (at most once per 10 minutes) or restarts the core. If the tunnel still fails, it releases Telegram's proxy so Telegram doesn't hang on a dead tunnel. Before this, a dead free config was reused forever and only a reinstall helped.
- New "Обновить бесплатный конфиг" button.
- When the AWG config is IPv4-only, IPv6 destinations are rejected right away and Telegram uses IPv4 while AWG is connected. This fixes `missing IPv6 local address`.
- The keepalive defaults to 25 s.
- A core that fails to load is no longer deleted and re-downloaded in a loop.
- The free config is downloaded over verified TLS.

## Stability
- The IPv6 switch now actually works in the .elyx build.
- Config sections load independently, so one bad section no longer resets everything, and the backup config can be restored.
- The .plugin auto-update writes the file atomically and keeps a `.bak`. It skips releases that need a newer exteraGram.
- Auto-update downloads only when GitHub has a newer release.
- Unloading the plugin no longer leaves Telegram on a dead `127.0.0.1` proxy.
- The core no longer stops, starts or hashes on the UI thread, a second Go runtime can't load in one process, and a crash-loop guard protects startup.
- TG-WS:
  - no thread or socket leaks on network switches;
  - no hang on stop;
  - a self-healing accept loop;
  - shorter, self-healing WS cooldowns.
- One broken subscription node no longer breaks the balanced config.

## AWG free config sources
- Cloudflare WARP is available as a second free config source (Selector "Бесплатный конфиг" plus a "Сгенерировать новый WARP" button). Each generation is a new, unique registration.

## Subscriptions
- Shadowsocks:
  - SS-2022 and plain `method:password` links;
  - `plugin=` (obfs-local, v2ray-plugin).
- Other link and subscription formats:
  - hysteria2 port hopping;
  - sing-box JSON subscriptions;
  - sudoku links in single-line subscriptions.
- Fetches have a 40 s deadline and an 8 MB size cap.
