# GreenPass 2.6.4

Плагин переписан с нуля: вместо одного большого файла теперь небольшие отдельные модули.

- Ядро встроено в плагин. Его не нужно скачивать отдельно: при первом запуске оно распаковывается и проверяется по хэшу.
- Убраны остатки кода чужих плагинов и пустые встроенные подписки.
- Новый контроллер подключений: одновременно работает только один режим, переключения больше не мешают друг другу.
- Страницы настроек стали короче и понятнее, переводы на английский и китайский обновлены.
- Настройки, узлы, подписки и профили из прошлых версий сохраняются.

Важно: старые версии (2.6.3 и раньше) не умеют обновляться сами до этой версии, потому что файл стал больше (в нём ядро). Установите GreenPass.plugin или GreenPass.elyx вручную один раз, дальше обновления снова будут приходить сами.
