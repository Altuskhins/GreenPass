# GreenPass 2.6.2

- .elyx: fixed missing settings and "nothing works". Some Elyx versions loaded the helper WEB proxy class instead of GreenPass, because two BasePlugin subclasses were visible in main.py.
- AWG: fixed "proxy does not connect" after 2.6.1. The Telegram proxy apply gave up after 3 s while the UI thread was busy (e.g. right after Telegram starts), which left the core running with no proxy set.
- AWG: Cloudflare WARP is now the default free config source. Each user gets their own registration. A VPgram choice made earlier is kept.
- Auto-update now checks every 3 hours. "Проверить обновления" still checks immediately.
