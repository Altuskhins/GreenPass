# GreenPass 2.6.3 (сборка 10)

- One update check every 24 hours, and the "Проверить обновления" button runs it right away. It covers:
  - the plugin itself: a new build is downloaded immediately and offered for installation;
  - the native core: it is checked against this build's manifest and re-downloaded if it is missing or outdated;
  - TG WS: when TG WS is running, the Cloudflare domain list is refreshed from upstream tg-ws-proxy.
