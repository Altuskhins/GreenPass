# GreenPass 2.6.4

This release rolls the plugin code back to 2.6.0, the last version that worked for everyone, and re-applies only small, contained fixes. The large 2.6.1-2.6.3 rework (threading, config loading, health checks) is withdrawn. In those versions Telegram kept showing "Соединение..." on 127.0.0.1 in every mode.

- .elyx: settings are back. Some Elyx versions loaded the helper WEB proxy class instead of GreenPass.
- AWG: VPgram is removed. It answers HTTP 406 "No available server". "Получить AWG конфиг" now generates a personal Cloudflare WARP config: each press is a new, unique registration. A VPgram config already saved keeps working until it is replaced.
- IPv6 switch: it now really works in .elyx, and only affects signed-in accounts.
- Auto-update: checks every 3 hours and downloads only when a newer release exists.
