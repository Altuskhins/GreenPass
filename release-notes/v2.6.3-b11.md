# GreenPass 2.6.3 (сборка 11)

- Custom ports.
  - "Дополнительно → Локальные порты": set your own 127.0.0.1 port for sing-box/VLESS, TG WS, AmneziaWG and olcRTC. Leave the field empty to use the default. The new port takes effect after the mode restarts.
  - AWG page, "Порт WARP": a fixed UDP port for the Cloudflare WARP server. Leave it empty for a random one (2408, 500, 1701 or 4500).
