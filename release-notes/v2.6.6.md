# GreenPass 2.6.6

- .plugin auto-update no longer overwrites the installed plugin file in place. That could leave the plugin "enabled, but with no settings" after an exteraGram restart until it was reinstalled from the channel. A found update is now saved and offered through exteraGram's own installer ("Доступно обновление → Установить"), the same way as the .elyx build.
- If GreenPass is already broken after a restart, reinstall it once from the channel or from this release.
